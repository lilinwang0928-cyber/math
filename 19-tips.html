1–100 質數大全

2-1

100 以內的質數剛好 25 個。下面橘框的六個數是最會騙人的——它們看起來像質數，其實都是合數。 91 = 7×13 就是原卷考過的那一題。

質數偵測器

輸入 2 到 9999 之間的整數，機器會照「除到平方根為止」的標準做法判斷，並把試除過程寫給你看。

1–100 全圖

綠色是質數（25 個），橘框是看起來像質數的合數，紫色的 1 既不是質數也不是合數。

質數 25 個 騙人的合數 1（非質非合） 其他合數
為什麼只要除到平方根就夠？如果 n = a×b 且 a ≤ b，那麼 a 一定 ≤ √n。 所以只要 √n 以內都找不到因數，就不可能有因數了。判斷 97 時，11² = 121 已經超過 97，試到 7 就可以收工。
02

倍數判別法 2–11

2-1

課本只教了 2、5、4、9、3、11 六條。這裡補齊 6、7、8、10，其中 7 的判別法是段考不考、但遇到大數字時最省時間的一招。

綜合掃描器

丟一個數進去，2 到 11 一次全部判完，每一條都附上判斷的理由。

2個位是 0、2、4、6、8看個位

只看最後一位是不是偶數，前面幾萬幾億都不用管。

24、68、102 都是。

3各位數字和是 3 的倍數看數字和

把每一位數字加起來，再看這個和是不是 3 的倍數。

123 → 1+2+3 = 6，6 是 3 的倍數 ✓

4末兩位是 4 的倍數看末兩位

因為 100 本身就是 4 的倍數，所以百位以上全部可以無視。

3128 → 末兩位 28 是 4 的倍數 ✓

5個位是 0 或 5看個位

只有這兩種結尾。

35、120 都是。

6同時是 2 和 3 的倍數兩條一起

6 = 2×3，而且 2 和 3 互質，所以兩條都過才算。

42 → 個位 2 是偶數 ✓、4+2 = 6 是 3 的倍數 ✓

7去尾、尾數×2、前數相減課本沒教

把個位切掉，剩下的數減去（個位×2）。數字還是太大就再做一次，直到看得出來為止。

203 → 20 − 3×2 = 14，14 是 7 的倍數 ✓

8末三位是 8 的倍數看末三位

因為 1000 是 8 的倍數，千位以上可以無視。

2008 → 末三位 008 = 8 ✓

9各位數字和是 9 的倍數看數字和

跟 3 同一招，只是門檻換成 9。

729 → 7+2+9 = 18 ✓

10個位是 0看個位

10 = 2×5，所以要同時滿足 2 和 5 → 個位只能是 0。

50、230 都是。

11交錯和是 0 或 11 的倍數最會錯

從個位開始一加一減交替算（個位＋、十位−、百位＋…）。也可以說成「奇數位和 − 偶數位和」，兩種講法是同一件事。

506 → 6 − 0 + 5 = 11 ✓

7 的判別法為什麼成立？設這個數是 10a + b（a 是去尾後的數、b 是個位）。 因為 20a + 2b 是 7 的倍數時 10a + b 也是，而 (20a + 2b) − 21a = 2b − a， 所以 a − 2b 是不是 7 的倍數，就決定了原數是不是。
03

因數全列表機

2-1・2-2

2-1 的配對機是用來「找」因數的；這一台是用來確保「不漏」。 先做質因數分解，再把每個質因數的指數系統性地組合，一個都跑不掉——順便得到因數個數公式。

指數組合法

輸入 1 到 99999 的整數。機器會列出標準分解式、指數組合表、所有因數，以及因數個數的算法。

因數個數公式：若 n = pa×qb×rc， 則因數共有 (a+1)(b+1)(c+1) 個。因為每個質因數的指數都可以從 0 挑到最大，各自有「最大指數 + 1」種選法。
順帶一提：因數個數是奇數的，一定是完全平方數（因為只有它會有一個因數自己配自己）。 回 2-1 用配對機對照
04

0 的特殊角色

2-1・總習題

「0 到底是不是因數？是不是倍數？」——答案是一邊是、一邊不是，而且理由來自同一件事： 整除的定義。

為什麼 0 不是任何整數的因數？

倍數 ÷ 因數 = 整數

因數要站在除數的位置。但除數不能是 0——除以 0 沒有意義，連算都算不出來。

✗ 0 當因數 → 除以 0 無意義

結論：0 不是任何整數的因數。

為什麼 0 是所有非 0 整數的倍數？

0 ÷ 非 0 整數 = 0（整數）

倍數站在被除數的位置，這裡完全合法：0 除以任何非 0 整數都等於 0，而 0 是整數。

✓ 0 = 任何非 0 整數 × 0

結論：0 是所有非 0 整數的倍數。

關鍵只有一句：整除要求被除數、除數、商都是整數，而且除數 ≠ 0。 0 可以當被除數，不能當除數——所以它能當倍數，不能當因數。

三十秒驗收

0 是 5 的因數。

0 不能當除數，所以不是任何數的因數。

0 是 5 的倍數。

5 × 0 = 0，成立。

5 是 0 的倍數。

要成立就得有 0 × 某整數 = 5，但 0 乘任何數都是 0，做不到。

1 是每一個整數的因數。

任何數 ÷ 1 都等於自己，是整數。

1 是質數。

質數要恰好兩個因數，1 只有一個 → 非質非合。

05

交換律為什麼重要

1-3・3-1

「2×3 = 3×2」看起來是小學的東西，但它其實是同類項合併的底層原理—— 沒有它，3-1 的化簡整套都不成立。

在代數裡也一樣

a × b = b × a

不管是數字還是英文字母，都可以交換位置。所以 xy 和 yx 是同一個東西。

12yx − 10xy = 12xy − 10xy = 2xy

這裡重要的不是答案是 2xy，而是你知道 yx 可以先寫成 xy—— 這一步就是在判斷「它們是不是同類項」。

分配律也是靠它推出來的

a(b + c) = ab + ac

長方形的面積怎麼切都一樣大：切成 ab 和 ac 兩塊， 跟整塊 a(b+c) 相等。

再往後一步，乘法公式也是同一件事：
(a+b)² = a² + ab + ba + b²
因為 ab = ba，才能合併成 a² + 2ab + b²。

國二的乘法公式、因式分解，全部站在這條規則上。

為什麼這一條值得單獨講：很多「不會」，追究起來只是某個基礎概念當年被跳過了。 交換律現在看只是一條小規則，但它決定了你之後能不能自由地重排一個長式子—— 而重排，正是 3-1 化簡和 3-2 移項在做的事。 去 3-1 用驗算器試一次
