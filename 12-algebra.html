代數式驗算器

化簡完不確定對不對？把原式和你的答案都貼進來，機器會代好幾個數字進去比對。 兩邊只要有一個數字對不上，就是化簡錯了——這招整個代數單元都能用。

變數：

01

列式與簡記

熟練 1・2・3
簡記三規則：乘號省略、數字寫在文字前面（寫 4a 不寫 a4）、除法寫成分數（y÷300 = y/300）。

熟練 1原卷未作答

乘號可以打 * 或省略（300x），分數用 /。

媽媽比小妍大 23 歲：小妍 x 歲 → 媽媽 歲； 媽媽 y 歲 → 小妍 歲

門票每張 300 元：買 x 張要付 元； 付了 y 元買了 張

看解析
「大 23 歲」是加、反過來就是減。第二組一個是乘、一個是除——誰當單價誰當總價要看清楚： 張數 × 300 = 錢，所以錢 ÷ 300 = 張數。

02

求代數式的值

熟練 4・5
代入時把 x 換成括號再放數字：−2x−1 代 x = −4 要寫成 −2×(−4)−1，這樣負號才不會弄丟。

熟練 4 代入表原卷未作答

x 值33/20−0.6−4
x+2
−2x−1

看解析
最右邊兩格最容易錯：x = −0.6 時 −2×(−0.6)−1 = 1.2−1 = 0.2； x = −4 時 −2×(−4)−1 = 8−1 = 7。負負得正之後才減 1。

熟練 5 應用原卷未作答

1.y = 9/5 x + 32，攝氏 30° 時華氏 = 度

2.成本 x 元加五成為定價 = x， 打 8 折後售價 = x， 成本 200 元時售價 = 元

看解析
9/5 × 30 = 54，54+32 = 86 度。
「加五成」是加 50% → 1.5x；「打 8 折」是乘 0.8 → 1.5x×0.8 = 1.2x；代 200 → 240 元。 加成用「1＋」、打折用「乘」，這兩個等一下 3-3 應用題會一直出現。

04

同類項的加減

熟練 7・8
只有同類項能相加減：有 x 的跟有 x 的合併、純數字跟純數字合併。 7x + 5 不能再合併成 12x——這是代數最常見的錯。

熟練 7原卷未作答

1.7x+5x = 　 2.−3x+(−4x) =

3.(−3/4 y)+3/5 y = 　 4.−1¼x+2¾x =

看解析
係數是分數就先通分：−3/4 + 3/5 = −15/20 + 12/20 = −3/20。
第 4 題先化假分數：−5/4 + 11/4 = 6/4 = 3/2 → (3/2)x 或 1½x。

熟練 8原卷未作答

1.3−6x−2x−7 =

2.2/3 y+1/4−1/2 y−1/5 =

3.2x+3x−(−4x)+(−2x)+1 =

看解析
分兩堆處理：有 y 的 2/3−1/2 = 1/6；純數字 1/4−1/5 = 1/20 → 答案是 (1/6)y + 1/20， 這兩堆不能再合併。
第 3 題：−(−4x) 變 +4x、+(−2x) 變 −2x → 2+3+4−2 = 7 → 7x+1。

去括號規則

熟練 9
括號前是「−」→ 裡面每一項都變號，一項都不能漏。這條規則在 1-2、1-3 已經出現過兩次，代數版本一模一樣。

口訣：負號進括號，每一項都翻面。第 6 題兩項都是負的，翻完全部變正 → 19+58x。

四則運算

熟練 11

熟練 11原卷未作答

1.3(5x−8)−(−2)(−9x−2) =

2.19x+5−8(8−2x)−9 =

08

分數與中括號

熟練 12
有分數就先通分（分子整包要加括號）；有中括號就由內而外拆。

熟練 12原卷未作答

分數形式的答案可以寫成 (3x-1)/12。

1.(3x−5)/6 − (x−3)/4 =

2.2(x/2−3)−3(2/3 x−1) =

3.9x+[−4x−(2x−1)] =

4.6b−(2b−8)−[−3+2(b+5)−12b] =

看解析
1. 通分成 12：[2(3x−5) − 3(x−3)]/12 = (6x−10−3x+9)/12 = (3x−1)/12。 分子整包都要乘，別只乘第一項。
3. 由內而外：先拆小括號 −(2x−1) = −2x+1 → 9x + [−4x−2x+1] = 9x−6x+1 = 3x+1。
4. 中括號內先算成 −3+2b+10−12b = 7−10b，前面是減號 → −7+10b； 合起來 4b+8−7+10b = 14b+1。這題用上面的驗算器對一次最保險。

10

四個最常見的誤區

先認得就不會踩

誤區一：不同類項硬合併

7x + 5 = 12x ✗。x 是未知的東西，跟純數字不能加在一起。 驗算法：代 x = 1，左邊 12、右邊 12；再代 x = 2，左邊 19、右邊 24 → 不相等，所以錯。代兩個數才保險。

誤區二：負號只變第一項

−(6−25x) = −6−25x ✗ → 正確 −6+25x。這是他在 1-2 熟練 11 已經踩過的同一隻怪，換成代數又出現。

誤區三：分配律漏乘後面那一項

−4/5 ×(−10y+1/12) = 8y ✗ → 後面的 1/12 也要乘，答案是 8y − 1/15。

誤區四：分數化簡時分子沒加括號

(3x−5)/6 − (x−3)/4 通分後分子要寫成 2(3x−5) − 3(x−3)， 整包一起乘。少了括號就會變成只乘第一項。
