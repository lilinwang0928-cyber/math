01

用文字符號列方程式

熟練 1
列式的關鍵是找出「哪個量算了兩次」。雞兔的腳、五邊形的內角和、學生的總人數——把兩種算法放在等號兩邊就對了。（題目說不必化簡。）

熟練 1原卷未作答

整條式子連等號一起輸入，例如 2x+4(18-x)=48。寫成等價的形式也算對。

1.雞兔同籠共 18 隻、腳共 48 隻，雞有 x 隻：

2.五邊形五個內角為 x、2x、3x、4x、5x：

3.一年級 x 班，每班 30 人多 12 人；每班 32 人少 16 人：

4.成本 a 元加 5 成為定價，打 8 折後獲利 100 元：

5.長方形長是寬的 3 倍少 5 公分、周長 150 公分，長為 y 公分：

看解析
1. 雞 x 隻 → 兔 (18−x) 隻；腳：2x + 4(18−x) = 48。
2. 五邊形內角和 = (5−2)×180 = 540。
3. 兩種編班算出來的學生人數是同一個：30x+12 = 32x−16。
4. 定價 1.5a、售價 1.5a×0.8、獲利 = 售價 − 成本 → 1.5a×0.8 − a = 100。
5. 長 y = 3×寬 − 5 → 寬 = (y+5)/3；周長 = 2×(長+寬) → 2(y + (y+5)/3) = 150。 這題最容易把寬寫成 3y−5，方向反了。
02

檢驗一元一次方程式的解

熟練 2
把數字代進去，左邊算一次、右邊算一次，相等就是解。這一關其實就是在教你怎麼幫自己的答案打分數。

熟練 2原卷未作答

−7 是 x−3 = −10 的解嗎？
5 是 −(3/5)x+3 = −10 的解嗎？
7/4 是 3(x−1¾) = 0 的解嗎？
−8 是 199[x−(−8)] = 0 的解嗎？

看解析
第 2 題：−(3/5)×5 + 3 = −3+3 = 0，不等於 −10 → 否。
第 3、4 題有個共同技巧：只要括號內變成 0，前面乘什麼都是 0。 x = 7/4 = 1¾ 讓括號歸零；x = −8 讓 [x+8] 歸零。
03

等量加法・減法公理

熟練 3・4
天平兩邊同時做一樣的事，還是平衡。要把 x 旁邊的數字趕走：它是被加的就兩邊同減，被減的就兩邊同加。

熟練 3 加法公理原卷未作答

1.a−0.59 = 2.13 → a = 　 2.(−12)+y = −12 → y =

3.x+(−73) = 26 → x = 　 4.(−2⅙)−(−b) = −5/6 → b =

看解析
第 4 題先整理左邊：−13/6 + b = −5/6 → 兩邊同加 13/6 → b = −5/6 + 13/6 = 8/6 = 4/3。
第 2 題答案是 0，不是無解——兩邊同加 12 就看出來了。

熟練 4 減法公理原卷未作答

1.x+12 = 35 → x = 　 2.a−(−5.7) = −1.2 → a =

3.7−b = 12 → b = 　 4.(−5)+x = −16 → x =

看解析
第 2 題：a+5.7 = −1.2 → a = −1.2−5.7 = −6.9。
第 3 題要小心：7−b = 12 → −b = 5 → b = −5（前面是 −b，最後要再變號一次，很多人停在 5）。
04

等量乘法・除法公理

熟練 5・6
x 被除了就兩邊同乘、被乘了就兩邊同除。除以分數＝乘倒數。

熟練 5 乘法公理原卷未作答

1.a÷2 = −1 → a = 　 2.b÷(−7/3) = 1 → b =

3.x÷200 = 0.4 → x = 　 4.a÷2⅔ = 1/2 → a =

看解析
第 4 題：2⅔ = 8/3，兩邊同乘 8/3 → a = (1/2)×(8/3) = 4/3。

熟練 6 除法公理原卷未作答

1.5x = 9 → x = 　 2.51y = −17 → y =

3.−13x = 26 → x = 　 4.−2.5x = 0 → x =

5.−(5/6)y = −30 → y = 　 6.−(3/4)y = 1 → y =

看解析
第 2 題：−17÷51 = −1/3（記得約分）。
第 4 題：0 除以任何非零數都是 0，不是無解。
第 5 題：兩邊同乘 −6/5 → y = (−30)×(−6/5) = 36，兩個負號變正。
05

移項法則

熟練 7
有 x 的移到一邊、數字移到另一邊，過等號就變號。移項其實就是等量加減公理的快寫法。

熟練 7原卷未作答

1.8x+3 = 5x+9 → x = 　 2.14−2x = −3x+4 → x =

3.2x−7 = −5x+14 → x = 　 4.3x−8 = −1−5x → x =

看解析
2. 14−2x = −3x+4 → −2x+3x = 4−14 → x = −10。x 的係數是負的時候特別容易掉符號，可以把 x 移到係數比較大的那一邊。
4. 3x+5x = −1+8 → 8x = 7 → x = 7/8。答案是分數也很正常，不要以為算錯。
06

去括號後解方程式

熟練 8
步驟固定：去括號 → 同類項合併 → 移項 → 兩邊同除係數。小數可以兩邊同乘 10 或 100 變整數再算。

熟練 8-1 ～ 8-4原卷未作答

1.6−2(2x+3) = 3(x+7) → x =

2.−3x+2 = 5(3x−7)+1 → x =

3.16+0.08x = 0.1(100+x)：兩邊同乘 → x =

4.0.03x−2 = 0.1x+1.5 → x =

看解析
1. 6−4x−6 = 3x+21 → −4x = 3x+21 → −7x = 21 → x = −3。
3. 同乘 100：1600+8x = 10(100+x) = 1000+10x → 600 = 2x → x = 300。 同乘的時候每一項都要乘，16 要變成 1600。
4. 同乘 100：3x−200 = 10x+150 → −7x = 350 → x = −50。

熟練 8-5 ～ 8-8中括號進階

5.4[x+3(x−2)]+1 = 5 → x =

6.2(3x+2)−2[5x−5(x−2)] = 6 → x =

7.x−[7−(3x+5)] = 6 → x =

8.4(3x+2)−[3−3(2x−1)] = −16 → x =

看解析
由內而外：先拆最裡面的小括號。
6. 中括號內：5x−5(x−2) = 5x−5x+10 = 10（x 全部消掉了），變成 6x+4−20 = 6 → 6x = 22 → x = 11/3。
7. 中括號內：7−(3x+5) = 2−3x，前面是減號 → x−(2−3x) = x−2+3x = 4x−2 = 6 → x = 2。
8. 12x+8−[3−6x+3] = 12x+8−(6−6x) = 18x+2 = −16 → x = −1。
這四題都可以用上面的天平驗算器代回去確認。
07

分數方程式

熟練 9
有等號才可以同乘去分母！兩邊同乘分母的最小公倍數，連沒有分母的那一項也要乘。（沒有等號的代數式只能通分，不能同乘——這是 3-1 和 3-2 最大的差別。）

熟練 9原卷未作答

1.(1/2)x+3 = (2/3)x−4：兩邊同乘 → x =

2.1−x/4−2(1−x/3) = 19：兩邊同乘 → x =

3.(x−3)/3−(x+6)/4 = 1：兩邊同乘 → x =

4.2(x+3)/5−3(x−4)/2 = 16：兩邊同乘 → x =

看解析
1. 同乘 6：3x+18 = 4x−24（+3 和 −4 都要乘）→ x = 42。
2. 先去括號：1−x/4−2+2x/3 = 19，同乘 12 → 12−3x−24+8x = 228 → 5x = 240 → x = 48。
3. 同乘 12：4(x−3)−3(x+6) = 12 → 4x−12−3x−18 = 12 → x = 42。
4. 同乘 10：4(x+3)−15(x−4) = 160 → 4x+12−15x+60 = 160 → −11x = 88 → x = −8。 分子有整包的式子，乘完要記得加括號。

關鍵判斷：可以同乘還是只能通分？最容易混淆

看到下面這些式子，你可以做的是——

x/2 + x/3 = 5
x/2 + x/3（沒有等號）
(x−1)/2 − (x+2)/3
(x−3)/3 − (x+6)/4 = 1

看解析
判斷方法只有一個：有沒有等號。
有等號 → 是方程式，兩邊同乘不會破壞等式，分母可以消失。
沒有等號 → 是代數式，同乘會把整個式子的值變大（x/2+x/3 乘 6 之後變成 5x，跟原式不相等），所以只能通分成 5x/6。
08

三個最常見的誤區

先認得就不會踩

誤區一：把代數式當方程式同乘

沒有等號時同乘公倍數，整個式子的值就變了。先看有沒有「=」再決定動作。

誤區二：去分母時漏掉沒有分母的那一項

(1/2)x+3 = (2/3)x−4 同乘 6，+3 要變 +18、−4 要變 −24。漏乘就整題錯。

誤區三：移項忘記變號

過等號一定要變號。這跟 1-2、1-3、3-1 的「去括號變號」是同一家族的怪——已經是第四次出現了。

老師備註
這三頁原卷完全空白。建議順序：②（檢驗解，先學會驗算）→ ③④（等量公理）→ ⑤（移項）→ ⑥⑦（去括號與分數）→ ①（列式）。 把列式放最後是因為它需要的是讀題轉譯能力，先把計算練順比較不會卡住。
每一題都要求代回去驗算——這一單元的答案可以百分之百自己確認，是建立信心最好的地方。
