走兩步實驗室

加法就是在數線上走兩步：先走 a，再走 b。正數往右、負數往左。拉滑桿看看什麼時候答案會變成負的。

05

減法就是加相反數

熟練 8
a − b = a + (−b)。把減法改寫成加法之後，就只剩「同號相加／異號相加」兩種情況。

先改寫成加法選符號

64 − (−85) = 64 □ 85
(−32) − 45 = (−32) □ 45
(−29) − (−74) = (−29) □ 74

看解析
減去一個負數＝加上它的相反數（變加正），減去一個正數＝加上負數。 口訣：「減負變加正」。

08

去括號規則

熟練 11
括號前面是加號 → 裡面照抄；括號前面是減號 → 裡面每一項都變號（不是只變第一項）。

先決定每一項的符號

9193 − (−7 + 9000) = 9193 □ 7 … 9000
… = 9193 + 7 □ 9000
(−625) − (−2009 − 625) = −625 □ 2009 … 625
… = −625 + 2009 □ 625

看解析
第二題括號內是 (−2009 − 625)，兩項都要變號：−2009 變 +2009，−625 變 +625。

熟練 11算出答案

1.9193−(−7+9000) =

2.(−625)−(−2009−625) =

看解析
1. 9193+7−9000 = 9200−9000 = 200（原卷 −6800，是把 +7 當成 −7 又直接減 9000）。
2. −625+2009+625 = 2009（原卷 −2009，符號整組弄反）。 也可以用另一招驗算：先算括號內 −2009−625 = −2634，再 −625−(−2634) = −625+2634 = 2009。兩種做法答案一致，才算對。

這三頁的五個陷阱

訂正重點

陷阱一：異號相加漏掉負號

熟練 4-1 寫成 49。先比絕對值決定符號，再算數字：75 > 26 → 答案是負的 → −49。

陷阱二：算到一半就當答案

熟練 9-2 停在 −2（還有 +(−47) 沒加）；熟練 7-1 湊 0 之後多寫了 9（250 寫成 259）。寫答案前數一次題目有幾項。

陷阱三：絕對值沒有先算裡面

熟練 10 有四題錯（2、3、5、6）。絕對值＝括號，先算成一個數，脫掉後一定非負，再接著做加減。

陷阱四：去括號只變第一項

熟練 11 兩題全錯。括號前是減號時，裡面每一項都要變號。可以用「先算括號內」再算一次來驗算。

陷阱五：距離反推只寫一個答案

熟練 13 兩題各漏一解。已知距離求座標 ⇒ 左右各一個答案，除非距離是 0。
