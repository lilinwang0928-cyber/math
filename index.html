使用方式

  • 建議順序：1-1 → 1-2 → 1-3 → 1-4 →（第一單元總複習）→ 2-1 → 2-2 → 2-3 → 2-4 →（第二單元總複習）→ 3-1 → 3-2 → 3-3 →（第三單元總複習）→ 第一至三單元總測驗。
  • 每一頁最上方都有「總覽」按鈕，可以隨時回到這一頁。
  • 每一關都有「檢查」按鈕，答對變綠、答錯變紅，可以立刻看解析再改。
  • 寫完一個單元可以去「概念檢核 趣學步道」對一次定義：算得出來不代表說得出來，那 21 格專門考規則本身。
  • 第三單元的三份是教學型（原卷空白），建議第一輪只做填空，把口訣練熟再往下。
  • 紀錄自動保存在瀏覽器（localStorage），關掉再打開會延續；換裝置或換瀏覽器則從頭開始。每份工具內都有「清除紀錄」。
  • 所有檔案放同一個資料夾就能互相連結。整包上傳 Netlify 或 GitHub Pages 即可，不需要伺服器設定。
  • 全部離線可用、無外部相依，手機直接開也可以作答。
