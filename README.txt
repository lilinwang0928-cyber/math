關於題目
═══════════════════════════════════════════

題目取自學生的計算熟練考卷（單元一～單元三）。

每一題的答案都用程式獨立驗算過：
分數與約分、最大公因數與最小公倍數、質因數分解、
指數律、代數式化簡、方程式的解（全部代回原式檢驗）。

代數式與方程式的判定採「數值比對」，
所以寫法不同但數值相同一樣算對，
例如 11x-3 與 10x+(x-3)、(7/8)x 與 0.875x。
