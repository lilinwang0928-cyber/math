觀念速記

寫題前先看一遍

3-1代數式的化簡

  • 簡記：數字寫在字母前、乘號省略；1x 寫成 x。
  • 同類項才能合併：3x+2 不能變成 5x。
  • 括號前是減號 → 裡面每一項都變號。
  • 分配律要乘進去每一項，包括最後那一項。
  • 不確定就代一個數字驗算（原式和答案要一樣）。

3-2一元一次方程式

  • 有等號才能同乘去分母，沒有等號只能通分。
  • 同乘時沒有分母的那一項也要乘。
  • 移項過等號要變號；x 的係數是負數時特別小心。
  • 解完一定代回原式，兩邊相等才交卷。

3-3應用問題

  • 四步驟：設、列、解、答。
  • 分配問題抓總數不變：多出用 +、不足用 −。
  • 年齡問題：n 年後兩個人都要 +n，年齡差不變。
  • 折扣：加五成 ×1.5、打八折 ×0.8、獲利 = 售價 − 成本。
  • 速率來回：去程時間 + 回程時間 = 總時間。

★ 三個最容易掉分的地方

  • 把代數式當方程式同乘（沒有等號卻消分母）。
  • 去括號只變第一項的號。
  • 算出 x 就交卷，忘了題目問的是總人數或兩個價錢。

代數式的化簡

第 1 ～ 6 題

代數式答案可以用 * 或省略乘號；分數係數寫成 3/2x 或 (3/2)x。寫法不同但數值相同一樣算對。

1文字符號的簡記3-1

y × (−1.2) =

看解析
數字寫前面、乘號省略 → −1.2y。寫成 y×(−1.2) 或 −1.2×y 都不算簡記完成。

2求代數式的值3-1

x = −3 時，−2x−1 =

看解析
−2×(−3)−1 = 6−1 = 5。代入時把 x 換成括號再放數字。

3同類項的加減3-1

−1¼x + 2¾x =

看解析
先化假分數：−5/4 + 11/4 = 6/4 = 3/2 → (3/2)x，寫成 1.5x 或 1½x 也對。

4去括號3-1

−(6 − 25x) =

看解析
兩項都要變號 → −6 + 25x = 25x − 6。寫成 −6−25x 是最常見的錯。

5分配律3-1

−4/5 × (−10y + 1/12) =

看解析
(−4/5)×(−10y) = 8y；(−4/5)×(1/12) = −1/15。後面那一項最常被漏掉。

6四則運算3-1

3(5x−8) − (−2)(−9x−2) =

看解析
(−2)(−9x−2) = 18x+4（負負得正），前面是減號 → 15x−24 −18x−4 = −3x−28。 分兩步寫：先算乘積，再處理減號。

第 7 ～ 9 題

7檢驗解3-2

5 是 −(3/5)x + 3 = −10 的解嗎？

看解析
代入：−(3/5)×5 + 3 = −3+3 = 0，不等於 −10 → 不是解。

8移項法則3-2

3x − 8 = −1 − 5x → x =

看解析
3x+5x = −1+8 → 8x = 7 → x = 7/8。答案是分數很正常。 驗算：3(7/8)−8 = −47/8；−1−5(7/8) = −47/8 ✓

9分數方程式3-2

(x−3)/3 − (x+6)/4 = 1

兩邊同乘 → x =

看解析
同乘 12：4(x−3) − 3(x+6) = 12（右邊的 1 也要乘）→ 4x−12−3x−18 = 12 → x−30 = 12 → x = 42。

應用問題

第 10 題

10分配問題3-3

新生編班：每班 26 人會多出 20 人；每班 30 人則不足 12 人。

設班級數 x：26x+20 = 30x（含正負號）→ 班級 班、學生 人

看解析
不變的是學生總數：26x+20 = 30x−12 → 4x = 32 → x = 8 班； 學生 26×8+20 = 228 人（用另一式驗算：30×8−12 = 228 ✓）。
題目若問「學生幾人」，只寫 8 班就白算了。
