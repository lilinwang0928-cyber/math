分配問題實驗室

分配問題是最愛考的一型。拉滑桿改題目的數字，看看方程式和答案怎麼跟著變—— 也順便看看什麼時候答案會變成不合理的小數。

00

題型雷達

看到關鍵字就知道要抓什麼

數字某數的幾倍加減

直接把「某數」設成 x，中文照順序翻成算式。「等於」就是等號的位置。 2x + 5 = x + 12

費用A 比 B 貴 k 元

設便宜的那個為 x，貴的就是 x+k。兩個加起來等於總價。 x + (x+k) = 總價

分配多出 / 不足

抓住總人數不變：兩種分法算出來的總數要相等。多出就 +、不足就 −。 ax + 多 = cx − 少

折扣加成、打折、獲利

加五成 = ×1.5、打八折 = ×0.8；獲利 = 售價 − 成本。 1.5x × 0.8 − x = 獲利

年齡幾年後

抓住兩人同時加同樣的歲數，年齡差永遠不變。先寫「現在」，再各自 +n。 (爸現在+n) = k(子現在+n) ± m

速率來回、往返

時間 = 距離 ÷ 速率；來回題把去程時間 + 回程時間 = 總時間。 x/去速 + x/回速 = 總時間

費用問題

熟練 2
設便宜的那個當 x，貴的寫成 x+k，這樣式子裡不會出現減號，比較不容易錯。

熟練 2原卷未作答

1.羽絨衣比毛衣貴 80 元，兩件共 380 元：設毛衣 x 元 → x+(x+80) = 380 → 毛衣 元、羽絨衣 元

2.咖啡比鬆餅貴 15 元，共 175 元：鬆餅 元、 咖啡 元

看解析
1. 2x+80 = 380 → x = 150，另一件 150+80 = 230。
2. 2x+15 = 175 → x = 80，咖啡 95。
算完一定要回頭加一次：150+230 = 380 ✓、80+95 = 175 ✓。這一步能抓住 90% 的粗心。
03

分配問題

熟練 3
不變的是「總人數」。每組 26 人還多 20 人 → 總人數 = 26x+20；每組 30 人還差 12 人 → 總人數 = 30x−12。兩個都是總人數，所以相等。

熟練 3原卷未作答

1.每班 26 人多 20 人、每班 30 人少 12 人，設班級數 x： 列式 26x+20 = 30x（含正負號）→ 班級數 = 班， 學生共 人

2.每組 30 人多 5 人、每組 32 人少 7 人 → 組數 = 組， 學員共 人

看解析
1. 26x+20 = 30x−12 → 32 = 4x → x = 8 班；總人數 26×8+20 = 228（用另一式驗算：30×8−12 = 228 ✓）。
2. 30x+5 = 32x−7 → 12 = 2x → x = 6 組；總人數 30×6+5 = 185（32×6−7 = 185 ✓）。
兩種算法都算一次總人數，對得上才算完成——這是分配問題自帶的驗算機制。
04

折扣問題

熟練 4
加 n 成 = ×(1+0.n)；打 n 折 = ×0.n；獲利 = 售價 − 成本。「獲利 25%」指的是賺了成本的 25%。

熟練 4原卷未作答

1.成本提高 80% 為標價、打九折出售、獲利 310 元： 標價 = x，售價 = x， 成本 = 元

2.標價 6000 元打八折，獲利 25%：售價 = 元， 列式 x+0.25x = 售價 → 成本 = 元

看解析
1. 1.8x×0.9 = 1.62x，1.62x − x = 310 → 0.62x = 310 → x = 500。
2. 售價 6000×0.8 = 4800；成本 + 獲利 = 售價 → 1.25x = 4800 → x = 3840。
兩題的差別：第 1 題獲利是「一個固定金額」，第 2 題獲利是「成本的百分比」， 列式方式完全不同，讀題時要看清楚獲利後面接的是「元」還是「%」。
05

年齡問題

熟練 5
n 年後兩個人都要 +n，一個加另一個沒加是最常見的錯。年齡差則永遠不變。

熟練 5原卷未作答

1.爸爸現在＝小恬的 4 倍少 1 歲；3 年後爸爸＝小恬的 3 倍多 2 歲。設小恬現在 x 歲：
3 年後小恬 (x+3) 歲、爸爸 (4x) 歲（填 −1+3 的結果）→ 小恬 歲、爸爸 歲、相差 歲

2.外婆現在＝熙熙的 5 倍多 3 歲；6 年後外婆＝熙熙的 4 倍少 3 歲 → 熙熙 歲、外婆 歲、相差 歲

看解析
1. 3 年後：爸 4x−1+3 = 4x+2、小恬 x+3 → 4x+2 = 3(x+3)+2 → x = 9；爸 4×9−1 = 35；差 26。
2. 6 年後：外婆 5x+3+6 = 5x+9、熙熙 x+6 → 5x+9 = 4(x+6)−3 → x = 12；外婆 63；差 51。
檢查法：年齡差現在是 26，3 年後 38−12 = 26，永遠一樣。差變了就是算錯了。
06

速率問題

熟練 6
時間 = 距離 ÷ 速率。來回題設單程為 x，去程時間 + 回程時間 = 總時間。單位要先統一（分鐘就全部用分鐘）。

熟練 6原卷未作答

1.逆風每分 150 公尺、順風每分 250 公尺，來回共 2 小時 40 分： 總時間 = 分，列式 x/150 + x/250 = 160 → 單程 公尺 = 公里， 比賽路程（來回）= 公里

2.逆風每天 100 公里、順風每天 130 公里，往返共 23 天 → 距離 公里

3.上坡時速 2、下坡時速 4，往返共 3 小時 → 距離 公里

看解析
1. 同乘 750：5x+3x = 120000 → x = 15000 公尺 = 15 公里（單程）。 題目問「比賽的路程」，選手實際跑的是來回 → 30 公里。 若老師的解答本認定「路程」＝賽道單程長，則為 15 公里，可對照一下。
2. 同乘 1300：13x+10x = 29900 → 23x = 29900 → x = 1300 公里。
3. x/2 + x/4 = 3 → 同乘 4：2x+x = 12 → x = 4 公里。

08

三個陷阱

應用題最常掉分的地方

陷阱一：算出 x 就交卷

分配問題問的常常是「總人數」而不是組數；費用問題問的是兩個價錢而不是只有 x。 算完 x 一定要回頭看題目最後一句在問什麼——這隻讀題怪已經出現第五次了。

陷阱二：幾年後只加一個人

3 年後爸爸和小孩都要 +3。檢查法：年齡差算兩次（現在、n 年後），必須一樣。

陷阱三：忘了檢查合理性

人數、個數必須是正整數。算出 6.25 串不是計算錯，而是情境本身不成立，要寫出理由。
