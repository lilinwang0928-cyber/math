指數展開機

指數律不用背——把它拆開寫成一長串，答案自己就跑出來了。選一個規則，拉滑桿看看展開後發生什麼事。

01

分數的乘方

熟練 1
(a/b)ⁿ = aⁿ / bⁿ：次方要分子分母各分一份。
負分數要先把負號收進括號：(−1½)⁵ = (−3/2)⁵ = (−3)⁵ / 2⁵。

(−2/9)3 = (−2)□/9□，□ = 　 (−1½)5 = (−3)□/2□，□ =

看解析
這四題的 □ 都等於原本的次方，因為次方只是「乘幾次」，分子分母都被乘同樣的次數。
第 4 題要先把帶分數化成假分數：1½ = 3/2，所以 (−1½)⁵ = (−3/2)⁵ = (−3)⁵/2⁵。
02

乘方的比較大小

熟練 2
底數大於 1 → 次方越大值越大；底數在 0 和 1 之間 → 次方越大值反而越小（因為每乘一次都在打折）。

熟練 2原卷寫了前兩題

(4/5)3 □ (4/5)4
(5/4)4 □ (5/4)5
0.72 □ 0.73
1.123 □ 1.124

看解析
判斷順序：先看底數跟 1 比誰大。4/5 和 0.7 都小於 1 → 次方越多越小；5/4 和 1.12 都大於 1 → 次方越多越大。
驗算：0.7² = 0.49、0.7³ = 0.343，確實變小了。
03

同底數相乘

熟練 5
aᵐ × aⁿ = am+n（指數相加）。條件是底數必須一樣。理由：7² × 7³ 就是 (7·7)×(7·7·7)，總共五個 7。

熟練 5原卷未作答

三個以上一起乘也一樣，全部相加：10+3+12 = 25。
底數是 (−5) 或 (−5/3) 都沒關係，只要三個底數長得一模一樣就能用。
04

同底數相除

熟練 6
aᵐ ÷ aⁿ = am−n（指數相減）。理由：7⁵ ÷ 7³ 就是把五個 7 約掉三個，剩兩個。

54÷53 = 5□，□ = 　 (−2/3)7÷(−2/3)□ = (−2/3)2，□ =

第 3 題答案是 1，不是 0——51 就是 5 本身，別把它寫成 50。
第 4 題是反過來問：7 − □ = 2 → □ = 5。看到未知數在指數位置，就把式子寫成減法再解。
05

乘方的乘方

熟練 7
(aᵐ)ⁿ = am×n（兩個指數相乘）。理由：(5⁷)² 是「兩個 5⁷ 相乘」＝ 7+7 = 14 個 5。這裡是乘不是加，最容易跟上一條搞混。

熟練 7原卷未作答

(156)4 = 15□，□ = 　 [(−8)6]3 = (−8)□，□ =

[(3/4)2]3 = (3/4)□，□ = 　 [(−20)8]6 = (−20)□，□ =

看解析
分辨方式看有沒有括號：57×52 是相乘（7+2 = 9），(57)2 是乘方的乘方（7×2 = 14）。 寫題目時把括號圈起來，就不會混。

兩數相乘的乘方

熟練 8
(a×b)ⁿ = aⁿ × bⁿ：括號外的次方要發給裡面每一個因數。
注意：只有乘除可以這樣分，加減不行（(a+b)² ≠ a²+b²）。

看解析

四個最常見的誤區

先認得，就不會踩

誤區一：把「相乘」的指數也相乘

7² × 7³ = 7⁶ ✗ → 正確是 7⁵。有括號才相乘：(7²)³ = 7⁶。分辨方法就是找括號。

誤區二：底數不同也硬合併

2³ × 3³ = 6⁶ ✗ → 指數律要求底數相同；這題該用 (2×3)³ = 6³。指數一樣時可以合併底數，不是合併指數。

誤區三：負號沒被括號包住

−3⁴ = 81 ✗ → −3⁴ = −(3⁴) = −81；(−3)⁴ 才是 81。 同理 5/2² 是 5/4，只有 2 被平方。

誤區四：把加法也分配進去

(a+b)² = a²+b² ✗ → 只有乘除能把次方分給每一項。可以用 (1+2)² = 9 ≠ 1+4 驗證。
