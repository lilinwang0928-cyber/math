2四則．負號4 分

(-12) + (-3) × (-4) - (-5) = ?

解析
先乘除：(-3)×(-4) = +12（負負得正） (-12) + 12 - (-5) = (-12) + 12 + 5 = 5 兩個要同時顧：乘出來是正 12，減負數變加 5。只漏一個就會得到 -7 或 -5。

5應用．連續變化4 分

冷凍庫最初溫度是 -2°C，設定成每 5 分鐘下降 3°C，則一個小時之後溫度是多少 °C？

解析

下列哪一個選項，其值為正數？

解析
只看正負，不用算大小。規則兩條：括號有沒有包住負號、次方是奇數還是偶數。 (A) (-4)75：負的，奇次方 → 負 (B) -476：負號在外面沒被包 → 先算 476 再加負號 → 負 (C) -(-4)77：(-4)77 是負，前面再加負號 → 正 ✓ (D) -(-4)78：(-4)78 是正，前面再加負號 → 負 (B) 最常錯：-476 不等於 (-4)76，沒括號就輪不到負號先上。

7數線．邊界4 分

在數線上比 3.5 小且比 -4.25 大的整數共有幾個？

解析
-4.25 < 整數 < 3.5 -4、-3、-2、-1、0、1、2、3 → 8 個 兩個常漏的：0 也是整數，還有負的那一端 -4 有被包進去（-4 比 -4.25 大）。 寫出來數，不要心算個數。

8絕對值．等距4 分

數線上 O、A、B、C 四點如圖。若點 D 所表示的數為 d，且 |d-5| = |d-c|，則關於 D 點的位置，下列敘述何者正確？

解析
|d-5| 的意思是「d 到 5 的距離」，|d-c| 是「d 到 c 的距離」。兩個距離相等 → D 是 5 和 c 的中點。 d = (5 + c) ÷ 2，而 c 落在 -5 和 0 之間 c 最小接近 -5 → d 接近 0；c 最大接近 0 → d 接近 2.5 所以 d 一定在 0 和 2.5 之間 → 介於 O、B 之間 不必知道 c 到底是多少。絕對值 = 距離，看到就先翻成距離，題目立刻變簡單。

957 × (-319) 的計算結果與下列哪一算式相同？

解析
957 = 950 + 7 957×(-319) = (950+7)×(-319) = 950×(-319) + 7×(-319) 而 7×(-319) = -7×319，所以可以寫成 950×(-319) - 7×319 ✓ (B) 看起來很像，但它是 減 7×(-319)，等於多加了一次 → 變成 943×(-319)。 拆完之後把負號跟著搬，這題就只剩看符號。

10應用．移動距離4 分

海平面上 100 公尺以「+1」表示，海平面下 100 公尺以「-1」表示。一隻海鳥在 +5 的位置垂直俯衝到 -3 捉魚，再垂直衝出海面到 +8，則這隻海鳥共移動了多少公尺？

解析
第一段：|5 - (-3)| = 8 單位 第二段：|8 - (-3)| = 11 單位 共 19 單位，一單位 = 100 公尺 → 19 × 100 = 1900 兩個坑一起踩才會錯：一是「共移動」要兩段相加（不是從 +5 直接到 +8 的 3 格）， 二是最後要乘回 100。(A) 1000 就是只算頭尾；題目問「共移動」就是走過的全部路。

12數線．細分刻度4 分

將數線上 -2 和 -1 之間的長度以小隔線分成八等分，A 點在其中一條隔線上，則 A 點表示的數為何？

解析
A = -2 + 6×(1/8) = -2 + 6/8 = -2 + 0.75 = -1.25 = -1¼ (C)(D) 可以直接刪掉：A 在 -2 和 -1 之間，不可能比 -2 還小。 剩下 (A) -1.25 和 (B) -1.75，差別就在你是從 -2 往右數還是從 -1 往左數。 負數往右是變大：-2 加上 0.75 要往 0 靠，所以是 -1.25。

13科學記號．負次方4 分

樂透彩頭彩中獎機率約為五百萬分之一，表示成科學記號應為下列哪一個？

解析
五百萬分之一 = 1 ÷ 5000000 = 0.0000002 小數點往右搬 7 格才到 2 的後面 → 2×10-7 (A)(B) 是看到「五百萬」就把 5 抄下來——但 5 在分母，倒過來是 0.2，不是 5。 遇到「幾分之一」先實際除出來，不要直接搬數字。

14數線．平移4 分

數線上，若點 A(-15) 向右移動 25 個單位到達點 B(b)，則 b 是下列哪一個數？

15絕對值．不等式4 分

|a| < 3½，且 a 為整數，則滿足此條件的 a 共有幾個？

解析
|a| < 3.5 的意思是「a 到 0 的距離小於 3.5」 → -3.5 < a < 3.5 整數：-3、-2、-1、0、1、2、3 → 7 個 (A) 5 是忘了 0 和漏掉一邊；(C) 9 是把 ±3.5 兩端也算進去。 絕對值不等式一定要展開成兩邊，只想正的那半就會少一半。
