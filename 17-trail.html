01正數與負數1-1

04整數的加法1-2

a、b 為正數時：(−a)+(−b) = −(a+b)；a+(−b) = +(a−b)；(−a)+b = −(a−b)（其中 a > b）。

(−9)+(−4) = (9+4)； 11+(−6) = (11−6)。

看解析
同號相加 → 符號照抄、數字相加；異號相加 → 跟絕對值大的那個同號、數字相減。

05整數的減法1-2

1. 無論 a 為正數、0 或負數，a 與其相反數的和為 。
2. 減去一個數，就相當於加上這個數的 。

(−2)−3 = −2+； 7−(−5) = 7+。

06數線上兩點距離1-2

數線上 A(a)、B(b) 兩點間的距離記作 AB， AB = | |。

若 A(3)、B(−4)，則 AB = |3−| = 7。

看解析
寫 a−b 或 b−a 都可以，因為外面有絕對值，結果一樣。

07負數相乘的正負1-3

偶數個負數相乘，乘積為 ； 奇數個負數相乘，乘積為 。

08指數記法1-4

將 a 連乘 m 次，可簡記為 的指數形式， 其中 為底數、 為指數。

12標準分解式2-1

將質因數由小而大相乘，遇到相同的質因數連乘時以指數表示，這種表示方式稱為 。

看解析
90 = 2×45 = 2×9×5 = 2×32×5。輸入 2*3^2*5。

13最大公因數的求法2-2

由兩數的標準分解式中找出共同的質因數，再由共同的質因數中分別取指數 者相乘。

(22×35, 2×32×5) = 。

看解析
共同的質因數是 2 和 3（5 只有一邊有），指數取小的 → 21×32 = 18。 填 2*3^2 或 18 都算對。

14最小公倍數的求法2-2

由兩數的標準分解式中找出全部的質因數，再由全部的質因數中分別取指數 者相乘。

[22×35, 2×32×5] = 。

看解析
全部質因數 2、3、5，指數取大的 → 22×35×5 = 4860。 只有一邊有的 5 也要帶走——這正是跟最大公因數相反的地方。

15異分母的加減2-3

16倒數2-3

當兩個數的乘積為 1 時，稱這兩個數互為 。 除以一個不為 0 的數，就是乘以這個數的倒數。

19一元一次式的化簡3-1

一元一次式的化簡， 需合併， 不是 不能合併。

看解析
有 x 的：3x+5x = 8x；純數字：−6−9 = −15 → 8x−15。這兩堆不能再合併。

20方程式的解3-2

看解析
