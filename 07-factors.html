01

列出所有因數

熟練 1
找因數的方法：從 1 開始一個一個試，找到一個就把配對的另一個一起寫下來（1 和 44、2 和 22、4 和 11），試到兩個數碰頭就停。

先讀題：這一大題要你交出什麼？原卷答錯位置

「將 44 寫成 a×b，並由小到大寫出 44 的所有因數」→ 要交的是
「M 的因數由小到大排列為 1、2、3、6、a、14、b、M，則 a＝？b＝？」→ 要交的是

看解析
原卷把熟練 2 的答案（a=7、b=21、c=8、d=32）寫進了熟練 1 的格子，所以熟練 1 其實沒有作答。 這兩大題的標題一樣都是「因數的應用」，但要交的東西完全不同：一個要你列清單，一個要你求未知數。 作答前先把題目最後那句話圈起來。

因數之間用逗號隔開，例如 1,2,4,11,22,44（順序要由小到大）。

1.44 = 1×44 = 2× = 4×
44 的所有因數：

2.28 = 1×28 = 2× = 4×
28 的所有因數：

看解析
44：1×44、2×22、4×11，試到 5、6…都不行，7 之後就會跟 11 碰頭 → 共 6 個因數。
28：1×28、2×14、4×7 → 1, 2, 4, 7, 14, 28。用上面的配對機驗算一次最快。
02

頭尾配對找出那個數

熟練 2
關鍵性質：把因數由小到大排好之後，第一個×最後一個 ＝ 第二個×倒數第二個 ＝ …＝ 那個數本身。所以只要有一組完整的配對，就能算出那個數。

熟練 2-1M 的因數

1、2、3、6、a、14、b、M

已知完整的一組配對是 3 和 14 → M = ， 再配對：6×a = M → a = ， 2×b = M → b =

看解析
共 8 個因數，頭尾一一配對：1↔M、2↔b、3↔14、6↔a。所以 M = 3×14 = 42， a = 42÷6 = 7，b = 42÷2 = 21。驗算：42 的因數是 1,2,3,6,7,14,21,42，順序完全吻合。

熟練 2-2N 的因數・有陷阱

1、2、4、c、16、d、N

完整的一組配對是 4 和 16 → N = ， c = ， d =

看解析
N = 4×16 = 64，d = 64÷2 = 32。
c 比較特別：64 = 8×8，配對的兩個數是同一個，所以 8 在清單裡只出現一次，正好卡在 4 和 16 中間 → c = 8。 這種「因數個數是奇數」的數叫完全平方數（4、9、16、25、36、64…），可以用配對機輸入 36 看看。
03

2、5 的倍數

熟練 3
只看個位數：個位是 0、2、4、6、8 → 2 的倍數；個位是 0 或 5 → 5 的倍數；同時是 2 和 5 的倍數 → 個位一定是 0。

熟練 3原卷全對

多個答案用逗號隔開，例如 2,4,6,8。

1.五位數 8351□ 是 5 的倍數也是 2 的倍數，□ =

2.四位數 395□ 是 2 的倍數但不是 5 的倍數，□ =

看解析
第 2 題要同時滿足兩個條件：是 2 的倍數（0,2,4,6,8）但不是 5 的倍數（排掉 0）→ 2, 4, 6, 8。
04

4 的倍數

熟練 4
只看末兩位：末兩位形成的數是 4 的倍數，整個數就是 4 的倍數（因為 100 本身是 4 的倍數）。前面幾百幾萬完全不用管。

熟練 4-1原卷全對

看解析
末兩位：96、28、40、44、36、52 都是 4 的倍數；22、55、50、25、50、98 不是。 特別注意 999998 的末兩位是 98，不是 4 的倍數（雖然它是 2 的倍數）。

看解析

05

3 與 9 的倍數

熟練 5・6
看各位數字的和：數字和是 3 的倍數 → 原數是 3 的倍數；數字和是 9 的倍數 → 原數是 9 的倍數。
順序很重要：9 的倍數一定是 3 的倍數，但 3 的倍數不一定是 9 的倍數。

熟練 5-1原卷全對

下列哪些是 9 的倍數？（可複選）

看解析
495→18、666→18、7659→27，都是 9 的倍數。
容易誤判的：468732→30、2838→21、5793→24、6630→15，這些是 3 的倍數但不是 9 的倍數。

熟練 6-1原卷全對

同一組數中，哪些是 3 的倍數？（可複選）

看解析
不是 3 的倍數的只有三個：920（和 11）、919（和 19）、1276（和 16）。其餘九個都是。

熟練 5-2・6-2

多個答案用逗號隔開。

三位數 36□ 是 9 的倍數，□ =

四位數 5□62 是 3 的倍數，□ =

看解析
36□：3+6+□ = 9+□，要是 9 的倍數 → □ = 0 或 9（別漏掉 0）。
5□62：5+□+6+2 = 13+□，要是 3 的倍數 → 13+□ = 15、18、21 → □ = 2、5、8。
06

11 的倍數

熟練 7
交錯和：從個位開始，一加一減交替算（個位＋、十位−、百位＋…）。結果是 0 或 11 的倍數，原數就是 11 的倍數。

熟練 7-1原卷全對

下列哪些是 11 的倍數？（可複選）

看解析
495：5−9+4 = 0 ✓　　468732：2−3+7−8+6−4 = 0 ✓
2838：8−3+8−2 = 11 ✓　　1276：6−7+2−1 = 0 ✓
其餘的交錯和都不是 0 或 11 的倍數。這一題四個全中，交錯和算得很穩。

熟練 7-2・7-3分步做

2.五位數 □3852 是 11 的倍數：交錯和 = 2−5+8−3+□ = +□， 所以 □ =

3.七位數 78□3526 是 11 的倍數：交錯和 = 6−2+5−3+□−8+7 = +□， 所以 □ =

看解析
第 2 題：2+□ 要是 11 的倍數，□ 只能是 0~9 → 2+□ = 11 → □ = 9（驗算 93852 ÷ 11 = 8532）。
第 3 題：5+□ = 11 → □ = 6（驗算 7863526 ÷ 11 = 714866）。
注意交錯和要從個位開始算，位數是奇數或偶數都一樣做。
07

質數與合數

熟練 8・9
質數：恰好只有 2 個因數（1 和自己）。合數：3 個以上因數。1 既不是質數也不是合數（它只有 1 個因數）。

熟練 8原卷全對

1.最小的質數 　 最小的合數 　 奇數中最小的質數

2.91 是質數還是合數？　 20 的因數中的質數：

看解析
91 看起來像質數，其實 91 = 7×13，是合數——考試最愛考這個數，還有 51 = 3×17、57 = 3×19。
20 的因數是 1, 2, 4, 5, 10, 20，其中的質數只有 2 和 5。

熟練 9原卷全對

n 個邊長 1 的小正方形拼成矩形，可以拼出幾種不同形狀？

n = 15 → 　 n = 17 → 　 n = 18 → 　 n = 36 →

看解析
矩形的種數 = 因數配對的組數。15 → 1×15、3×5 共 2 組；17 是質數只有 1 組；18 → 1×18、2×9、3×6 共 3 組。
36 有 9 個因數（奇數個），因為 6×6 自己配自己 → (9+1)÷2 = 5 組。用配對機輸入 36 就看得到。

三秒防守法

作答前把題目最後一句圈起來，問自己：要交的是「一個數」、「一串數」還是「是或不是」？寫完再回頭看一次那個圈。
